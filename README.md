# Phantombite_Core

Basis-Mod der Phantombite Mod Suite für Space Engineers: zentrales Command-System (`!pbc`),
Logger, GlobalConfig, Performance-Überwachung und Mod-zu-Mod-Messaging.

Entwickler-Doku: `DEV_Funktion.md` (Aufbau), `DEV_Anbindung.md` (neuen Mod anbinden),
`DEV_TODO.md` (Roadmap und offene Punkte), `DEV_History.md` (Änderungen).
